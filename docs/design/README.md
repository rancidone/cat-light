# Historical ESP32 design notes

These documents describe the retired ESP32 firmware, not CatLightPocket. Fixes to that firmware will be considered on demand; there is no active implementation roadmap.

The original frontmatter statuses record design progress at the time. “Implemented” does not mean verified or free of known bugs, and draft proposals are not commitments. Some notes predate the move into `esp32/`; resolve firmware and web asset paths relative to that directory.

Start with [system design](system.md), the [discovery brief](../discovery/v2-firmware-discovery.md), or the [retired firmware guide and known issues](../../esp32/README.md).
